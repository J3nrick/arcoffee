# ARCOFFEE — VISUAL & ARCHITECTURAL GUIDELINES

## ARCOFFEE Visual Rule
When improving or extending the interface, prefer:
- **TYPOGRAPHY**
- **PHOTOGRAPHY**
- **COMPOSITION**
- **SPACING**
- **EDITORIAL METADATA**
- **BRAND LANGUAGE**

Over:
- **CARDS**
- **PILLS**
- **EMOJIS**
- **ICONS**
- **GRADIENTS**
- **GLASS**
- **SHADOWS**
- **DECORATIVE BLOBS**

If the page feels empty, do **NOT** automatically add another component.
First ask whether the existing composition, photography, typography, or spacing is weak.

ARCOFFEE should feel like a real independent lifestyle brand, not an AI-generated UI template.

Apple HIG controls interaction quality and usability (44pt touch targets, WCAG AA contrast, responsive breakpoints, spring curves).
ARCOFFEE's brand system controls visual identity (Editorial Coffee × Pickleball Club).
